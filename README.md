# Quantitative Model Building Sandbox

This repository holds both training data and Jupyter Notebooks for a collection of different quantitative prediction models. As such, each sub-folder within the repository contains a single production-ready model created for a specific use case/business case. The applications for these models vary and are largely dependent on how people choose to use them.

### Models

All models are saved as <b>joblib</b> (Python-Specific Serialization)<br>
However, raw Notebook files are provided, allowing others to duplicate the model specific training process or for saving the model in their desired format.
