# Quantitative Model Building Sandbox

This repository holds a collection of production-ready quantitative prediction models along with Jupyter Notebooks used for training them. As such, each sub-folder within the repository contains a single model created for a specific use case. The applications for these models vary, and are largely dependent on how people choose to use them.

### Models

- All models are saved as <b>joblib</b> (Python-Specific Serialization).
- The raw Notebook files are provided, allowing individuals to re-train models as desired.
- Model cards is also provided, explaining model specs, mechanisms, and evaluations.
